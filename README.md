# Колледж кітапханасының веб-сайты (College Library Website)

## 📌 Жобаның мақсаты
Бұл жоба студенттер мен оқытушыларға колледж кітапханасының кітап қорын онлайн режимінде қарауға, қажетті әдебиеттерді іздеуге және электронды ресурстарға қол жеткізуге мүмкіндік беретін веб-қосымша құруға арналған.

## 🛠️ Қолданылатын технологиялар
- **Тілдер:** PHP, HTML5, CSS3, JavaScript
- **Сервер:** Apache HTTP Server
- **Мәліметтер базасы:** MySQL
- **Контейнерлеу:** Docker

## ✨ Негізгі мүмкіндіктер
- Кітаптар каталогын қарау және іздеу (авторы, атауы және шыққан жылы бойынша).
- Кітаптардың қолжетімділік күйін тексеру (кітапханада бар немесе қолданыста).
- Пайдаланушыларды тіркеу және жеке кабинет.
- Кітаптарды броньға қою немесе уақытша алуға тапсырыс беру.
